## Project Overview
This project presents a comparative analysis of Convolutional Neural Networks (CNN) and Transformer-based deep learning models for date palm classification using hyperspectral imagery. The study evaluates the performance of both approaches in identifying and classifying date palm samples using hyperspectral data.

## Objectives
- Preprocess hyperspectral image data.
- Train and evaluate CNN models.
- Train and evaluate Transformer models.
- Compare classification performance.
- Analyze the effectiveness of deep learning techniques for hyperspectral image classification.

## Dataset

This project uses the Palm Tree Hyperspectral Dataset collected from Al Ain, United Arab Emirates.

Dataset Source:
https://github.com/NourO93/Palm-Tree-Dataset
